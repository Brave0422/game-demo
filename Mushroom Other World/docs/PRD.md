# 《蘑菇异界：双雄闯关》（暂名）PRD

版本：v0.2，补充需求与一致性修订版  
日期：2026-10-11  
用途：私人学习与朋友试玩的经典角色同人游戏  
目标：交给 AI 实现一个可以完整游玩的 Godot 首版。

## 1. 产品定义与决策来源

一款明亮手绘卡通风格的 2D 横版动作游戏。玩家在开始前选择魂斗罗角色或经典洛克人，在蘑菇草地与地下城中跑跳、射击、破坏物体并获取角色专属武器，最后击败具有明确攻击机制的怪兽 Boss。

以下为用户已确认的硬性要求：

| 项目 | 已确认要求 |
| --- | --- |
| 技术 | Godot |
| 工程规范 | 目录设计、文件命名与代码逻辑遵循 Godot 官方/主流惯例，采用场景就近组织、节点组合、带类型 GDScript；见 [CODING_STANDARDS.md](CODING_STANDARDS.md) |
| 审查注释 | 每个变量（含局部变量）、方法、关键节点均有中文职责注释；方法注明参数及副作用，关键分支说明规则原因，场景节点使用 editor_description |
| 首版内容 | 两个角色、一个完整关卡、一个最终 Boss |
| 平台与模式 | PC，单人，键盘操作 |
| 角色 | 魂斗罗人物、经典洛克人；洛克人支持跑跳、射击、蓄力，首版不加冲刺与蹬墙跳 |
| 生命 | 两人都使用血量，受伤后短暂无敌，掉坑死亡 |
| 魂斗罗武器 | 按原作字母武器设计；拾取后替换当前枪 |
| 洛克人武器 | 参考经典系列；获取后可切换，普通弹无限，特殊武器消耗能量 |
| 首关主题 | 蘑菇草地与地下城，怪兽 Boss |
| 重试 | 无限重试，从最近检查点复活，Boss 门前有检查点 |
| 破坏物 | 砖块只能从下方顶破；武器箱只能攻击打破；少量障碍两种方式都能破坏 |
| 美术 | 完全非像素；明亮、活泼的手绘卡通，参考《恶果之地》的观感，也可参考《失落城堡》的手绘处理 |
| 素材 | 实施 AI 自行上网搜索、下载、检查并接入美术、音乐和音效；免费优先，视觉缺口可 AI 制作或重绘，无需用户提供素材 |
| 普通怪物 | 五种，核心机制不同；仅荆棘滚兽有持续身体接触伤害，其他怪物只在明确攻击或敌弹命中时伤害玩家 |
| 首关时长 | 首次正常探索的有效游戏时间 14–18 分钟，包含 Boss；排除暂停、死亡界面和死亡/手动重试造成的重复进度 |

本 PRD 其余内容是为使 AI 能直接实施而补齐的设计默认值，包括角色具体人选、武器组合、操作键位、数值、关卡长度、Boss 招式与存档范围。它们不是用户逐项确认的事实；实现时先采用这些值，试玩后可通过配置调整。硬性要求优先于默认值。

上述表格沿用原文已有要求，并纳入本轮新增要求；时长口径和仅荆棘滚兽触碰受伤已在本轮确认。新增怪物具体数值、机关和检查点数量属于本次设计默认值。产品规则以本 PRD 为准；[TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md) 规定实现分工，[QA_CHECKLIST.md](QA_CHECKLIST.md) 将规则转为测试步骤；支持文档不得悄悄覆盖 PRD。审查结论见 [REVIEW_NOTES.md](REVIEW_NOTES.md)。

首版成功标准：两名角色分别能从角色选择进入同一关卡，完成跳跃与射击、五种不同机制敌人、三类破坏交互、武器获取、机关与有限遭遇战、检查点复活、两阶段 Boss 和通关结算；所有正式画面都符合统一的非像素美术方向，时长经过试玩校准。

## 2. 首版范围与后续扩展

首版必须交付：主菜单、角色选择、操作提示、一个固定设计的关卡、两名角色、魂斗罗四种特殊枪械、洛克人三种特殊武器、五种普通敌人、一个两阶段 Boss、起点 CP0 与五处途中检查点 CP1–CP5、移动平台与开关门、两场有限遭遇战、暂停与音量设置、通关结算、素材名单和 Windows 可运行导出包。

首版暂不实现：双人或联网、手柄、移动端、随机地图、关卡编辑器、商店、装备养成、复杂剧情、额外角色、第二个完整关卡。魂斗罗的 R、B 等辅助强化也放到后续版本。

完整游戏的长期方向仍是多关卡、每关独立 Boss、击败 Boss 后进入下一关。首版只有一关，胜利后显示结算页，可选择重玩、换角色或返回菜单。关卡配置预留 `next_level_id`；存在实际下一关时才显示进入下一关按钮，最后一关走通关流程。

首关首次正常探索的有效游戏时间目标为 14–18 分钟，中位目标 16 分钟；不要求寻找隐藏路线。熟练速通允许更短，暂估 7–10 分钟，不以强制等待限制速通。屏幕数与怪物数量只是灰盒起点，不能直接证明时长达标；具体统计和验收见第 6、10、14 节。

## 3. 游戏流程与操作

流程：主菜单 → 角色选择 → 首关 → 检查点 → Boss 门前补给 → Boss 战 → 结算。

死亡：播放约 0.8 秒死亡反馈 → 显示“从检查点重试” → 按确认键复活。暂停菜单同时提供从检查点重试、重新开始本关、返回主菜单。

| 动作 | 默认键位 | 规则 |
| --- | --- | --- |
| 左右移动 | A / D 或 ← / → | 同时按左右时水平输入为 0 |
| 上下方向 | W / S 或 ↑ / ↓ | 用于魂斗罗瞄准；下方向可趴下 |
| 射击 | J | 魂斗罗可按住连射；洛克人基础武器支持蓄力 |
| 跳跃 | K | 按住跳高，松开降低上升高度 |
| 切换武器 | Q | 洛克人在已获得武器中循环；魂斗罗不响应此操作 |
| 直接选武器 | 1 / 2 / 3 / 4 | 洛克人对应普通弹、回旋切刃、冰冻波、火焰风暴；未获得的槽位不可选 |
| 暂停 / 返回 | Esc | 冻结游戏物理、敌人、子弹、计时与蓄力 |
| 菜单确认 | Enter 或 J | UI 接管输入，避免同时触发场内射击 |

UI 使用简体中文。进入首关时，以安全区域的短提示教会移动、跳跃、射击和破坏；角色选择页展示角色差异及武器规则。

## 4. 角色与移动手感

### 4.1 共用基础规则

两人使用同等的基础移动和跳跃能力，使同一个关卡都能通过。暂不加入二段跳、滑铲、游泳、攀爬和踩怪攻击。怪物身体不作为落脚平台，也不阻挡玩家移动。仅荆棘滚兽的刺壳在非冻结且存活状态下接触扣血（包括踩到顶部）；其余四种普通怪的身体无害，但玩家进入其正在生效的攻击区域仍会受伤。Boss 身体默认无接触伤害，只按招式区域判定。

设计坐标以 1280×720 为基准视口，世界坐标单位与基准视口中的像素一致。地形逻辑格为 64×64，使用高清非像素贴图；使用网格不代表像素画风。

| 参数 | 初始值 |
| --- | --- |
| 最大血量 | 8 HP |
| 水平速度 | 320 单位/秒 |
| 地面加速 / 减速 | 2400 / 2800 单位/秒² |
| 空中加速 | 1800 单位/秒² |
| 重力 | 1800 单位/秒² |
| 初始跳跃速度 | -820 单位/秒 |
| 松开跳跃时的上升速度上限 | 若仍向上且速度小于 -320，则截到 -320 |
| 离地宽限 / 跳跃输入缓存 | 0.10 / 0.12 秒 |
| 最大下落速度 | 1100 单位/秒 |
| 普通受伤无敌 | 1.2 秒 |
| 复活保护 | 1.5 秒 |
| 荆棘滚兽刺壳接触 / 普通敌人攻击伤害 | 1 / 1 HP |
| Boss 扑砸伤害 | 2 HP |

站立碰撞体约 42×88，角色视觉高度约 112，统一脚底锚点。蓄力、换枪等视觉不改变碰撞体。受伤有轻微击退与闪烁，无敌期间不重复扣血；仍持续接触刺壳时，无敌结束可再次扣血。击退默认水平 180、向上 180 单位/秒，水平控制锁定 0.12 秒；同帧多伤害源取最大单次伤害，只触发一次击退与无敌。死亡判定区无视无敌。

理论完整跳跃高度约 187，平地空中水平距离约 292。主线台阶高度不超过 128，坑宽不超过 192；更复杂的组合需两人分别实测。跳跃落点应有至少 128 宽的安全平台。

### 4.2 魂斗罗角色

默认人物为 Bill Rizer，以红头巾、持枪突击兵的识别特征进行非像素卡通重绘。

移动中可水平、斜向上、斜向下射击；原地按上可向上射击。地面按下且没有左右输入时趴下并沿面朝方向射击；空中单独按下时向下射击。地面下加左右输入仍行走并斜向下射击。所有斜向方向使用归一化向量，射速和弹速不因方向变化。

趴下碰撞体约 60×36，脚底位置保持一致。上方被阻挡时不得强行站起。趴下可躲避部分弹道，主线不安排只有魂斗罗才能通过的低矮通道。

武器无限弹药，拾取立即替换；受伤不掉枪，死亡按检查点快照恢复。

### 4.3 经典洛克人

保留蓝色头盔、装甲、靴子和手炮，按同一画风重绘。普通弹和首版特殊武器均向当前面朝的水平方向发射，跳跃时仍可射击。通过地形与敌人摆放保证无需朝上射击也能完成主线。

普通弹按下 J 时发射一颗，随后持续按住开始蓄力；快速松开不额外再发一颗。松开时根据持有时长发射：不足 0.4 秒无追加弹，0.4 至不足 1.1 秒为中弹，达到 1.1 秒为大弹；达到阈值本身不自动发射。普通弹不消耗能量；特殊武器不蓄力，可按住按各自射击间隔使用。切换武器、死亡或离开关卡时取消蓄力。

## 5. 武器、弹道和掉落

本作采用经典行为的同人改编，并非某一部原作的逐帧复刻。洛克人组合使用经典系列的蓄力基础炮与经典特殊武器；不能把特殊武器写成只有颜色不同的普通子弹。

### 5.1 魂斗罗武器

| ID / 名称 | 弹道与作用 | 伤害 | 最短射击间隔 |
| --- | --- | --- | --- |
| `contra_default` / 普通枪 | 沿瞄准方向单发直线弹，按住连射 | 1 | 0.18 秒 |
| `contra_m` / M 机枪 | 更密集的直线弹 | 1 | 0.10 秒 |
| `contra_s` / S 散弹 | 每次 5 颗，围绕瞄准方向 -20°、-10°、0°、10°、20° | 每颗 1 | 0.32 秒 |
| `contra_l` / L 激光 | 快速细长射弹，最多穿透 3 个不同普通敌人，碰实墙停止 | 3 | 0.45 秒 |
| `contra_f` / F 火球 | 火球沿前进轴传播，同时绕前进轴作小幅旋转/波动，宽覆盖 | 3 | 0.40 秒 |

普通弹、M、S 弹速约 900，L 约 1200，F 约 650。F 横向偏移半径约 24，属于移动的火球弹，不做持续喷火柱。子弹出屏外 160 或存活超过 2 秒时回收。

S 同一发散弹对 Boss 的总伤害上限为 2，普通敌人可受到多颗命中；L 对同一目标一颗弹仅结算一次，命中 Boss 后回收。除明确允许穿透/返程再命中的武器外，玩家弹命中有效目标后回收。敌方子弹碰实墙或玩家即消失（包括玩家无敌时）；地面波沿地面行进，到墙或竞技场边界消失。此处是首版平衡改编。

### 5.2 洛克人武器

每种特殊武器有独立的 28 点能量。初次拾取解锁、补满该武器并自动装备；重复拾取恢复该武器 14 点能量，不强制改变当前装备。能量不足时不生成子弹、不扣到负数，自动切回基础炮并显示短提示。

| ID / 名称 | 行为 | 伤害 / 能量 | 最短射击间隔 |
| --- | --- | --- | --- |
| `mega_buster` / 基础炮 | 普通直线弹；中蓄力、大蓄力弹更大 | 普通 1、中弹 2、大弹 5；不耗能 | 普通 0.18 秒 |
| `mega_cutter` / 回旋切刃 Rolling Cutter | 向前上方弧线飞出再返回；去程、返程各最多命中同一敌人一次 | 每次命中 2 / 每发 2 能量 | 0.55 秒，场上最多 1 个 |
| `mega_ice` / 冰冻波 Ice Slasher | 水平冰刃，冻结普通敌人 2.5 秒；冻结期间停止移动、攻击和接触伤害 | 普通敌人 0 伤害；Boss 弱点 2；每发 2 能量 | 0.45 秒 |
| `mega_fire` / 火焰风暴 Fire Storm | 水平火球，同时产生持续 0.6 秒的近身火焰环，强调近身输出 | 火球 3、火环每目标每次施放最多 1；每发 3 能量 | 0.50 秒 |

基础炮普通弹场上最多 3 颗，蓄力弹最多 1 颗；中/大蓄力弹共享上限。达到上限时不发射、不排队补发，释放的蓄力被清空并给出轻提示；普通弹上限不妨碍开始蓄力。切刃返回后回收，不返还能量；最大前进距离约 300，碰实墙开始返回，返程不穿墙，遇墙直接回收，最长 2 秒强制回收以免永远占槽。冰刃和火球碰实墙或有效目标回收。冰冻不生成可站立平台，Boss 不会被冻住。火焰环不提供无敌、不阻挡敌弹，不隔墙命中；同一次施放的火球与火环可各命中一次，Boss 合计最多 4 伤害。切换武器不清除已发射的弹体。

基础炮弹速约 900，冰刃约 650，火球约 700，切刃总往返约 1.2 秒。蓄力弹对普通敌人可穿透最多 2 个不同目标，碰墙或命中 Boss 后回收。

### 5.3 物体与补给

| 物体 | 有效破坏方式 | 初始耐久 | 内容 |
| --- | --- | --- | --- |
| 顶破砖块 | 角色向上跳跃、头部撞击其底面 | 1 次有效顶撞 | 固定小回复道具或空内容 |
| 武器箱 | 玩家攻击 | 3 点攻击伤害 | 按当前角色映射固定武器 |
| 裂纹障碍 | 顶撞或玩家攻击 | 1 次顶撞或 2 点攻击伤害 | 可选捷径、小回复道具或空内容 |
| 普通地形 | 不可破坏 | — | 无 |

侧面、踩踏和下降过程撞到砖块均不触发顶破。砖块受到子弹时仅给出硬质反馈，子弹停止；顶破后移除碰撞并播放碎片。敌人的攻击不破坏这些物体。冰刃对可攻击破坏物仍造成 1 点耐久伤害，避免当前武器无法开箱。

箱子在地图中配置补给槽，开箱时读取角色，不能掉落另一个角色的武器：

| 补给槽 | 魂斗罗 | 洛克人 | 关卡用途 |
| --- | --- | --- | --- |
| A | S | 回旋切刃 | 草地区域体验群体攻击 |
| B | L | 冰冻波 | 地下城体验穿透或控制 |
| C | F | 火焰风暴 | 地下城体验火焰武器 |
| D | M | 回旋切刃，重复时补能 | 草地支路提供可选奖励 |

拾取采用角色接触。图标带名称或字母和独特轮廓；出现时轻微弹出并落到安全地面，不因短计时消失。若落入死亡区域，移动到配置的安全落点，不能永久丢失。开箱、生成掉落、拾取每个实例只执行一次；连续火力不得复制掉落。

回复道具固定布置，首版不加入随机掉落：小回复恢复 2 HP，大回复恢复 4 HP，满血时保留在场内。能量道具恢复当前特殊武器 8 点；若当前武器能量已满或使用基础炮，则恢复能量最低的已解锁武器，平局按 2、3、4 槽顺序。没有特殊武器或所有特殊武器能量已满时，能量道具保留在场内，不被消耗。

## 6. 首关设计：蘑菇草地与地下城

### 6.1 路线与时间预算

灰盒以约 34 个主线屏幕单元为起点，等效水平长度约 43520 世界单位；局部竖向房间按实际路径安排，不强制铺成一直线。两种环境属于同一关卡，切换环境不重置角色武器。约 136 秒的理论纯直线跑动不能代表游戏时长，剩余体验必须来自有意义的战斗、跳跃、机关与探索，不能靠加长空走廊填充。

| 区段 / ID | 屏幕单元 | 中位预算 | 必经体验、补给与检查点 |
| --- | --- | --- | --- |
| 安全教学 / S1 | 1–3 | 1.5 分钟 | 起点 CP0；三类破坏物安全练习、A 箱；离开练习区后遇到首只巡逻蘑菇；末端 CP1 |
| 草地错落平台 / S2 | 4–8 | 2 分钟 | 巡逻近战和喷吐弹道组合、两组短坑；可选支路 1 放 D 箱与小回复，支路不计主线时长预算 |

### 6.2 新增机关与遭遇战

移动平台共 4 组，2 组水平、2 组竖直。宽度至少 160，速度默认 80 单位/秒，单程距离 160–240，端点停留 0.3 秒。主线候乘不超过 4 秒；周围至少 128 宽安全地面，首组下方是可走回的地面。平台不夹死玩家、不穿实体墙；被阻挡时暂停运动，移开后继续。随平台运动不会增加角色最大跳跃速度；无下穿单向平台操作。

开关共 2 处，只接受玩家攻击一次激活（冰刃同样有效），不增加交互键。开关、对应门及连接线须在同屏可理解；永久打开当前会话中的门，无限时跑门。按钮命中判定独立于伤害值，不能因冰刃 0 伤害失效。门打开后有稳定回路，不依赖可消耗武器、敌人站位或破坏唯一平台。此处“永久”仍遵循检查点快照回滚规则。

E1、E2 各 6 只，分为两批各 3 只，均包含在上述 52 只中。E1 第一批为 2 巡逻 + 1 喷吐，第二批为 1 巡逻 + 2 盾壳；E2 第一批为 2 蝙蝠 + 1 喷吐，第二批为 1 荆棘 + 1 盾壳 + 1 喷吐。入场触发关闭两端门，清完本批后预警 0.8 秒生成下一批，清完立即开门；不设置计时生存或无限刷新。生成点可见、距玩家至少 256，玩家靠近预定点时使用同屏备用点，场地须足够大；不得在玩家身上生成。关门前确认玩家已完全入场，不能夹住角色。门内无死亡坑；两角色只用基础武器均能完成。冻结不等于击杀，出口须等实际死亡计数满足。

两条支路各约 30–60 秒，奖励非必需，总额外时长不计入主线验收；不加货币、商店、收集品套装或第三个环境。主线回复初始预算为 8 个小回复、4 个大回复，包含砖块内固定回复；大回复分配 E1 后 1 个、S6 中 1 个、门前 2 个。洛克人另有 4 份能量（S5、S6 各 1，门前 2），魂斗罗对应位置改成小回复。检查点补满血另计，支路奖励另计。门前补给主要用于进入 CP5 前补能及选择武器，未拾取物遵循快照保存。

### 6.3 公平性与调时规则

主线不可依赖特殊武器、趴下、朝上射击或精确极限跳跃。破坏砖块和障碍可以获得奖励或捷径，不能让玩家破坏唯一落脚点后无法继续。隐藏路线从主线可见，以裂纹、道具或蘑菇排列给出线索；首版最多 2 条。

镜头向角色前方偏移约 160，水平跟随并限制在关卡边界；局部竖向区域平滑跟随。Boss 战锁定房间镜头，所有落点预警与主要攻击必须在视野内。普通敌人只在玩家接近约 1.5 屏范围时开始活动；不在玩家身上、背后近距离或视野外直接生成攻击。

CP 周围至少 256 距离内是安全站立区域。进入下一段前能够看到足够的落地位置；敌弹不能穿越已锁住的 Boss 房入口追打门前角色。

非竞技场普通怪离开激活范围时保留 HP/死亡状态、暂停 AI，不因回走刷出新敌人；敌弹离开视野 160 单位或达到 5 秒寿命即销毁。尚未入镜的敌人可以移动但不得开始攻击预警。第 14 节的试玩若短于 14 分钟，优先补充有差异的路线组合和战斗互动；长于 18 分钟则减少重复遭遇和无效绕路。禁止靠提高普通怪血量、延长 Boss 无敌、强制等待或重复死亡达标。调整后同步屏幕预算、敌人配置与验收记录。

## 8. 最终 Boss：孢子大王

外观为大型蘑菇怪兽：夸张菌盖、粗壮短肢、明确表情，腹部有发光核心。视觉高度约 300、宽约 320；腹部核心中心距离地面约 70，使两人的平地水平射击都能命中。

基础 HP 为 120。平常身体有菌甲，只产生弹开反馈；攻击结束后菌甲展开、腹部发光，可受伤。所有玩家武器都能在暴露阶段造成有效伤害，Boss 战不要求特定武器。首版不采用属性免疫、强制换枪或击破独立肢体机制。

第一阶段按“扑砸 → 扇形孢子 → 地面孢子波”循环。预警、攻击、暴露、过渡四个状态明确，常规过渡 0.6 秒。攻击方向和目标在预警开始时锁定，预警形状与实际危险区域一致。

HP 小于等于 60 时进入第二阶段：在本物理帧全部伤害结算后只触发一次，立刻关闭核心、取消当前招式并做一次 1 秒怒吼，清除敌方攻击残留，菌盖颜色变暖；怒吼期间不攻击也不受伤。攻击循环改为“扑砸 → 地面波后接孢子 → 扇形孢子”。组合中的地面波与孢子至少间隔 0.65 秒，孢子有独立嘴部预警（不短于 0.70 秒），不同时封住地面和整个跳跃空间；组合完全结束后只给一次弱点窗口。弹速最多提高 15%，扇形孢子增加到 5 颗，暴露窗口缩短至 1.5 秒；预警时长保持不变。

扑砸飞行约 0.7 秒，空中身体无伤害，只有落地冲击区域生效 0.2 秒；落点限制在竞技场可站立范围，玩家看见标记后必须有足够距离横移躲开。Boss 与玩家身体不产生推挤，落地重叠不会困住角色。弱点窗口随落地冲击结束或末颗弹/波发出开始，旧弹仍可能存在，但须保留安全站位。扇形发射角初值以面向方向的水平线为中心，第一阶段为 -30°/0°/+30°，第二阶段为 -40°/-20°/0°/+20°/+40°（镜像到另一侧）；弹体半径默认 12，通过角色碰撞体实测调整角度与出生点，不能只凭图示认定可躲。开战时 Boss 固定出生点、玩家安全入场点至少相距 400 单位。

Boss 无冰冻效果，无弹体对同一碰撞目标逐帧重复结算。弱点窗口开始时还在场内的攻击可以命中弱点；窗口结束时立即关闭伤害接收。建议基础武器首次熟悉机制后的单次战斗约 90–150 秒，需两角色分别试玩验证。

## 9. 检查点、重试与保存

关卡开始自动建立 CP0 起点快照（8 HP、角色基础武器，洛克人特殊武器均未解锁），用于首次检查点前死亡。CP1–CP5 按第 6 节位置依次激活，回走不会把进度覆盖为更早检查点；每个检查点首次激活时将 HP 补满并保存快照，重复进入同一 CP 不再次补血或改写快照。检查点不补满武器能量。

快照内容：角色 ID、关卡 ID、检查点 ID 与出生点、当前武器、已解锁武器与各自能量、已破坏物体 ID、已死亡敌人 ID、已拾取道具 ID、开关/机关门状态、已完成遭遇战 ID、当前内容计时进度，以及尚未拾取的掉落物 ID/种类/数量/位置。对象需有稳定唯一 ID，不能依赖运行时节点顺序。门前不同 A/B/C 箱的可拾取物在地面上分隔至少 128 单位并标注名称，玩家用接触选择；避免一次经过同时换三次枪。

复活时重新加载关卡并应用快照：此前已破坏物体和已消灭敌人维持快照状态；快照之后的敌人、箱子和补给恢复；角色满血、武器和能量恢复到快照值；清空所有子弹、攻击特效和蓄力，复活位置无危险。活着的普通敌人从配置出生点重置，不要求恢复它们的精确行动位置。未拾取的掉落物按保存数据重建，避免箱子已破坏而掉落永久消失。

移动平台复位到各自配置起点；活敌 HP、冻结与 AI 回到初始状态。未完成遭遇战复位为未触发，清除该遭遇战所有临时实例，重入后从第一批开始；已完成遭遇战保持开门。检查点均放在遭遇战之外，不保存战斗中的半批敌人。动态敌人 ID 由遭遇战 ID、批次和序号组成，掉落 ID 由来源物体 ID 和槽位组成。

Boss 战重试回 CP5，Boss 恢复全血和第一阶段，房门重新开放，重新进入才启动战斗。CP5 放在门前补给之后，进入时建立快照；步行回门目标不超过 2 秒。到达后再回头拿补给不会改写快照，死亡后恢复原先的箱子、掉落、装备与能量。需要换装备时可在重试后重新选择，不允许重复刷出补给。

首版检查点仅在当前关卡会话保留；返回主菜单、重新开始或退出应用均清除快照，再进入从 CP0 开始，UI 提示本次进度将丢失。磁盘只保存音量、窗口模式、震动开关、每名角色是否通关与最佳挑战总用时（第 10 节定义）。主菜单不用“继续游戏”按钮暗示尚未实现的跨会话检查点保存。配置文件缺失或损坏时回到默认设置，不能阻止启动。

## 10. UI、音频与反馈

HUD 左上显示头像、当前/最大 HP；旁边显示当前武器图标与名称。洛克人显示特殊武器能量及 1–4 槽状态；基础炮显示无限符号。Boss 战上方显示名字、血量和阶段变化。

角色选择使用两个非像素立绘和简短说明；只选定一名角色进入关卡，关卡中不能换人。暂停页支持继续、从检查点重试、重新开始、主音量/音乐/音效调节、窗口/全屏、返回菜单。结算展示角色、内容用时、挑战总用时和死亡次数，可重玩或换角色。

计时仅在正常关卡游玩状态累计（包含受伤硬直、观察预警、等待平台等正常过程），菜单、暂停、死亡动画、死亡菜单、加载和胜利演出不计入。区分两个计时器：

- **内容用时**：用于 14–18 分钟验收；到检查点提交当前段时间，从检查点重试时丢弃未提交的失败段时间，最终由各检查点之间成功通过的尝试与最后成功的 Boss 尝试构成。正常探索、观察和可操作的教学计时。可选支路用进出区域单独计时，从主线验收值中扣除；结算同时标注支路额外用时。失败尝试带来的熟悉效应另在试玩记录中注明，不能据此冒充纯首次无死亡体验。
- **挑战总用时**：所有尝试的可操作时间总和，包含失败段和支路，重试不回退，用于最佳成绩；死亡次数仅在死亡时增加，手动重试另记重试次数，不伪装为死亡。重新开始本关或换角色清零两个计时器和次数。

射击、命中、硬甲弹开、开箱、拾取、顶砖、受伤、死亡、检查点激活、Boss 预警和通关均有对应音效。音乐划分草地、地下城、Boss、通关四种状态；同一关可将草地曲在地下城降调性或换编排，但不能只用音量降低制造所有差异。Boss 入场时音乐淡入淡出约 0.6 秒。

子弹和怪物攻击使用不同颜色与形状。危险预警同时依赖动画、形状和声音，不能只依靠颜色。镜头震动幅度小，受伤与 Boss 落地有短震动；设置中可关闭震动。关闭震动不影响伤害、碰撞与预警。

## 11. 美术与素材要求

正式方向：明亮手绘卡通、圆润比例、清晰深色轮廓、轻量手绘纹理。参考《恶果之地》的活泼感与读图清晰度，地下城可以参考《失落城堡》的石墙与灯光层次。参考作品仅作为美术方向，不作为可直接提取的素材库。

角色、怪物、场景、拾取物、UI 和特效必须完全非像素；不采用原版 NES 像素角色，不将像素图平滑放大充当手绘图。原作参考用于形象与玩法；两名角色都要按统一方向重绘。

资源与制作清单详见 [ASSETS.md](ASSETS.md)，画风约束及生成提示词详见 [art/ART_DIRECTION.md](art/ART_DIRECTION.md)。实施 AI 负责自行联网搜索美术、音乐、音效和字体，下载后实际查看/试听、核对来源和使用条件、处理风格并接入工程。候选链接不是任务完成证据；不得默认让用户找图或提供音乐。优先从现成免费资源寻找基础地形、道具、UI 和音频，找不到匹配的角色、五种怪物或 Boss 动作时再用 AI 制作/重绘。音乐同样必须主动网上筛选，不得省略或只留占位音。无法下载某来源先换源；网络、试听或生成工具能力确实阻塞时，报告具体缺口与尝试，不捏造已取得素材。

至少需要：两名角色完整动作、五个普通敌人动作、一个 Boss 的预警/攻击/暴露/死亡动作、草地与地下城各三层背景、两套地形、三类破坏物状态、移动平台、开关与机关门、武器图标及弹体、回复与能量道具、检查点与门、HUD 和菜单控件。图片透明区域正确，脚底与射击点锚点稳定，碰撞体不随动画晃动。

概念示意图用于画风与氛围讨论，不能作为已完成的角色动作表，也不能把其中的平台布局直接视为精确碰撞关卡。灰盒阶段可以使用临时图形，最终交付不保留占位素材。

## 12. Godot 实现约束

本节为 PRD 中的技术决策摘要，详细模块、数据结构、碰撞分层、恢复顺序和测试方案见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)，实施时必须一并阅读。

| 功能块 | 指定实现技术 | 职责边界 |
| --- | --- | --- |
| 输入、角色移动 | InputMap、CharacterBody2D、带类型 GDScript | 共用移动控制器，角色专用瞄准/武器策略 |
| 战斗与武器 | 自定义 Resource、Area2D、物理步扫掠检测 | 配置武器，集中结算命中/护甲/无敌，弹体不直接改 HUD |
| 五种敌人 / Boss | GDScript 显式有限状态机 | 预警、攻击、收招、冻结、死亡分离，不用一个追玩家脚本套所有怪 |
| 地图与机关 | TileMapLayer、PackedScene、AnimatableBody2D | 静态地形与可破坏实例分离，开关/门/平台独立组件 |
| 镜头与美术 | Camera2D、Parallax2D、Sprite2D、AnimationPlayer | 手绘分层动画优先，逻辑碰撞与视觉分离 |
| UI、暂停 | Control、Container、CanvasLayer、SceneTree 暂停 | 中文菜单/HUD、输入焦点、暂停下 UI 可操作 |
| 音乐与音效 | AudioStreamPlayer/2D、Master/Music/SFX 总线 | 音乐切换、淡入淡出、同类音效并发限制 |
| 会话与保存 | GameSession、Resource 配置、ConfigFile | 内存检查点快照；仅设置/成绩写入 user://，不依赖服务器 |
| 验证与发布 | Godot headless 测试脚本、实际试玩、Windows 导出模板 | 逻辑自动验证，画面/音频/手感人工检查，离线运行 |

默认使用 Godot 4.7.2 标准版、带类型的 GDScript、Compatibility 渲染器，目标 Windows x86_64。版本取自核对时的 [Godot 官方 Windows 下载页](https://godotengine.org/download/windows/)。如实现环境已有其他 Godot 4.x 稳定版，先核对兼容性并在 README 记录实际版本，避免混用 Godot 3 API。

基准视口 1280×720，保持 16:9，窗口尺寸不符时适配并保留画面完整；高清卡通素材使用线性过滤，禁用低分辨率像素视口与像素吸附。物理更新 60 Hz；所有速度、冷却、预警、能量和伤害参数配置化。

建议场景构成：

- `Player`：`CharacterBody2D`，共用移动/生命组件，角色专属瞄准与武器控制，视觉和碰撞分离。
- `Level`：多层 `TileMapLayer`、背景层、敌人、破坏物、掉落物、检查点和门。地形采用 Godot 官方的 [TileMapLayer](https://docs.godotengine.org/en/stable/classes/class_tilemaplayer.html)。
- `Projectile`：`Area2D` 或带扫掠检测的弹体，记录本弹已命中目标；快速子弹用射线/形状扫掠防止穿过薄墙。
- `Enemy` / `Boss`：有限状态机，分开预警、攻击、受伤和死亡状态；Boss 核心和装甲使用不同命中区域。
- `Breakable`：统一接口处理顶撞、攻击、耐久、一次性掉落；底面有效顶撞与侧面碰撞分开判断。
- `GameSession`：保存角色、本次计时、死亡次数和检查点快照；`AudioManager` 管理音频总线与音乐状态。
- `HUD` / `Menus`：`CanvasLayer` 下的 UI，与角色和战斗逻辑通过信号通信。

武器、敌人、关卡和掉落映射用自定义 `Resource` / `.tres` 配置，首版无需外部数据库或大型插件。区分玩家、普通敌人、敌弹、玩家弹、地形、拾取、危险区、可破坏物碰撞层与掩码。

角色和 Boss 推荐使用高清分层图与 `AnimationPlayer`，必要时配合 `Skeleton2D`；也可使用稳定对齐的手绘帧动画。必须同时覆盖移动与射击，不能跑步时枪口漂移、手炮方向和弹道不一致。

蓄力弹释放、武器切换和弹体数量上限的判定须统一：不能因一个输入事件生成两份蓄力弹，能量只在特殊弹体成功生成时扣除。暂停期间松开的射击键在恢复后仅取消蓄力，不自动补发一颗弹。

工程规范采用 [CODING_STANDARDS.md](CODING_STANDARDS.md) 与 [project_structure.md](project_structure.md)：场景和专属脚本放在同一功能目录，共享组件放 `components/`，全局服务放 `core/`，设计数据放 `resources/`。不再采用早期分离的镜像 `scripts/` 建议。用户要求所有变量、方法、关键节点具备中文注释，作为代码验收条件。

## 14. 验收标准

1. 从主菜单分别选择两名角色，进入同一完整关卡；人物形象、动作和 UI 都是非像素画风。
2. 两人均能通过主线最大台阶和坑；洛克人不依赖冲刺、蹬墙跳、朝上射击或特殊武器。
3. 砖块仅由上升时从下方顶破；攻击不能破坏它。箱子仅由攻击打破；裂纹障碍两种方式都可破坏。
4. 同一 A/B/C/D 箱因角色不同产生表内对应内容；一秒内受到多次攻击或同帧多弹命中也只生成一份掉落。
5. 魂斗罗 M/S/L/F 弹道与射速明显不同；拾取替换当前枪，受伤保留枪，无限子弹。
6. 洛克人基础炮具有普通/中蓄力/大蓄力；三特殊武器具有回旋、冻结、火球加火环行为，各自独立能量、可切换、无负能量。
7. 唯一持续接触伤害普通怪为荆棘滚兽；其他四种身体无害、仅明确攻击区/敌弹伤害。持续重叠刺壳时无敌期不扣血，结束可再扣；冻结与恢复宽限期无接触伤害。掉坑仍死亡；暂停冻结全部世界状态和计时。
8. 分别在 CP0–CP5 后死亡，出生点、武器、能量、开关/门/遭遇战和物体状态符合快照；未拾取掉落仍存在，没有重复奖励或残留子弹。
9. Boss 前死亡从 CP5 重试，回门步行不超过 2 秒；Boss 恢复满血和第一阶段，门、血条与音乐都可重新启动。
10. Boss 三招均有正确预警、可躲避路径与暴露窗口；半血转换只执行一次，第二阶段增加组合，装甲与核心伤害规则正确。
11. 两角色分别只用基础武器通关；同时击杀/死亡只进入一个结果状态。最终关胜利显示结算，未制作第二关时不出现不可用的下一关按钮。
12. 完成两角色的全流程试玩，专项检查散弹同帧命中、激光穿透、能量归零换武器、冻结解冻、顶砖重复碰撞、连续死亡及暂停恢复。
13. 1280×720、1920×1080 和窗口缩放下 HUD 无遮挡，字清楚、背景不露缝，子弹不穿墙，镜头不显示关卡外空白。
14. 在有明确 CPU/GPU/分辨率记录的测试 PC 上，同屏 5 怪和 80 个弹体的压力场景以约 60 FPS 为目标；记录实际结果，不凭空宣称性能达标。Windows 导出包能离线启动并完成流程。
15. 资源来源文件完整。正式版本的角色动作、Boss 动作、背景和音乐都已实际接入；素材候选列表或概念图不能替代此项验收。
16. 五种普通怪分别演示近战、定点射击、俯冲、持续接触和方向护甲机制；盾壳不能由穿透弹硬穿，基础武器可绕背/等开壳击杀。蝙蝠进入水平射击范围，冻结不会导致强制清怪房卡关。
17. 两组水平和两组竖向平台能搭乘、阻挡暂停且不夹死；两个开关可用基础弹和冰刃激活，门可恢复；E1/E2 各仅两批、每批 3 只，清完立刻开门且不能重复刷奖励。
18. 时长验收至少记录 6 次首次试玩（每角色至少 3 次，每次由此前未玩本 demo 的试玩者完成；不让熟悉首关的人冒充另一角色的首次玩家）。报告两角色各自的内容用时中位数，均应为 14–18 分钟，并列出全部样本、支路时间、挑战总用时、死亡/重试次数和卡住位置。目标不依赖隐藏支路；少于样本数或只有开发者试玩时只能标“待验证”。玩法改动后须重新校准，不能仅修改文档宣称达标。
19. 两种计时规则、暂停释放射击、首次 CP 前死亡、门前回拿补给、手动重试、返回菜单清空会话和损坏设置文件均按 [QA_CHECKLIST.md](QA_CHECKLIST.md) 验证。测试环境与证据据实记录，未运行项标记未验证。
20. 按官方 Godot 惯例组织目录、命名和代码职责；代码中的常量、变量、方法、重要分支及场景关键节点都有中文注释，遵守 [CODING_STANDARDS.md](CODING_STANDARDS.md)。不以自动生成的无信息注释代替职责说明。

## 15. 后续版本方向

首版验证手感后再扩充三关：第 2 关可为熔岩洞窟与火焰怪兽，第 3 关可为异界城堡与多阶段领主。届时实现实际关卡间转换、持续进度和角色跨关武器规则，再考虑更多人物与本地双人。新增关卡、Boss 和武器沿用配置与场景接口，避免重写已完成的战斗基础。
