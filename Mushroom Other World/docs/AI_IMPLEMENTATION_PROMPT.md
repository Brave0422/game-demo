# 交给 AI 的实施提示词

版本：v0.2，2026-10-11。以下是**将来明确要求生成游戏时**可发送的提示词模板；当前文档审查任务不因阅读本文就获得制作游戏的指令。

---

请在当前仓库实现一款 Godot 2D 横版动作游戏。先完整阅读 `docs/PRD.md`、`docs/TECHNICAL_DESIGN.md`、`docs/QA_CHECKLIST.md`、`docs/ASSETS.md`、`docs/art/ART_DIRECTION.md` 和 `docs/REVIEW_NOTES.md`。以本次用户指令和 PRD 用户已确认要求为优先，按其余明确默认配置实施；产品行为由 PRD 定义，技术方案和验收清单不得自行改写玩法。

目标是完成一个可编辑、可运行、可导出的完整首版：PC 单人键盘，两名可选角色（魂斗罗 Bill Rizer、经典洛克人），一个蘑菇草地与地下城关卡，五种普通敌人，一个两阶段怪兽 Boss。包含破坏取武器、角色专属弹道、血量与无敌、CP0–CP5 检查点无限重试、四组移动平台、两个攻击开关、两场有限遭遇战、菜单和 HUD、暂停、音频、通关结算。

首关按 PRD 八段约 34 屏幕单元的灰盒起点制作，首次正常探索主线内容用时目标 14–18 分钟，含 Boss、不依赖隐藏支路、不含暂停和失败重跑。内容用时按成功检查点段拼接，挑战总用时单独累计全部尝试；不能靠高血量、空走廊或强制等待填充时长。至少每角色 3 份真实首次试玩样本用于正式校准，只有开发调试数据时如实标为待验证，不虚构玩家测试。

所有最终视觉必须是明亮统一的非像素手绘卡通。两名经典角色也须重绘，不能采用 NES 像素角色，不得把像素图放大或开启平滑就称为手绘。画风示意图仅用于方向参考，不能当作已制作好的角色动画或精确关卡。

默认 Godot 4.7.2 标准版、带类型 GDScript、Compatibility、1280×720 基准视口、60 Hz 物理。若环境已有其他 Godot 4.x 稳定版，核对 API 兼容性后记录实际版本与匹配的导出模板。严格落实技术方案的模块表、数据契约、碰撞层、统一伤害入口、状态机与快照恢复顺序。使用配置化 `Resource`、独立场景和信号，避免用大量硬编码互相访问节点；无需后端或运行时联网服务。

工程目录、文件命名、代码逻辑完全按官方/主流 Godot 惯例统一，详细规则见 `docs/CODING_STANDARDS.md`。每个常量、变量（包括局部变量）、方法及关键节点必须附中文注释，说明职责、单位、参数、副作用与重要规则原因；`.tscn` 使用 `editor_description` 记录关键节点职责。审查时同时检查注释是否随实现更新，不能只为凑覆盖率写无信息说明。

按 PRD 的 A–E 阶段实施，素材搜索与下载可以提前进行。先验证移动与全流程，再完成资源和表现；中间灰盒可以用临时图形，最终版本必须替换。美术、音乐、音效和字体全部由你自行上网搜索、复核来源与许可、下载、实际查看/试听、处理并接入，不要默认让用户提供。`docs/ASSETS.md` 链接均为待复核候选，可以替换；缺失角色/Boss/五怪动作可用 AI 制作或重绘，暂不购买素材。无法获取某资源时先换源，若能力确实阻塞则报告具体缺口与尝试，不把未下载/未试听的素材宣称为完成。

重点正确实现：

- 砖块仅底面顶撞可破，箱子仅攻击可破，裂纹障碍两者均可；同一物体只掉落一次。
- 同箱按角色映射。魂斗罗拾取替换枪，无限弹药；M/S/L/F 行为不同，F 是旋转/波动前进的火球。
- 洛克人有普通/中/大蓄力弹，回旋切刃、冰冻波、火焰风暴与独立能量；重复武器补能，能量不足回基础炮。
- 两人基础武器均可通过所有主线与 Boss，主线无需朝上射击、趴下、冲刺或蹬墙跳。
- 五怪必须分别实现巡逻近战、定点喷吐、空中俯冲、荆棘滚动接触、盾壳方向防御。仅荆棘滚兽有持续身体接触伤害，其他怪物只在明确攻击时伤害；冻结关闭接触与近战，解冻有 0.5 秒安全恢复。
- 盾壳前壳不能被穿透弹绕过判定，基础武器可绕背或等开壳击败；冰冻不算击杀，不使遭遇战永久锁门。
- 四组平台可搭乘、不夹死，两个开关可用基础弹/冰刃激活；E1/E2 各两批三只，生成点安全且总量有限。
- CP0 自动建立，CP1–CP5 依序激活；快照恢复武器、能量、世界对象、开关/门和遭遇战状态，不产生复制掉落、遗失掉落或死亡后的弹体残留。Boss 重试位于 CP5，回门不超过 2 秒。
- Boss 预警准确、攻击有可躲避路径、收招暴露核心，半血只转阶段一次；同时击杀/死亡按 PRD 优先通关。
- 首版只有一关，完成后显示结算；下一关按钮只有实际下一关资源存在时才显示。

完成 PRD 全部验收项并记录 QA 清单结果；自动化验证重点覆盖掉落唯一性、接触/冻结/护甲、受伤无敌、武器能量/切换、快照恢复、计时回滚与 Boss 状态转换，操作手感、音频与视觉仍需实际运行试玩。记录测试环境和实际结果，不宣称未运行的测试、未试听的音频、未实测的性能或时长。

最终交付完整 Godot 工程、Windows x86_64 导出包、操作与启动 README、素材 manifest 和许可证、生成提示词、参数调整说明、验收结果与已知问题。资源链接或概念图不能替代正式资源接入；代码片段不能替代完整工程。
