# 首版美术方向

日期：2026-10-11，v0.2。方向沿用原文：完全非像素、明亮活泼、手绘卡通、免费素材优先，缺失可 AI 制作/重绘。实施 AI 先自行上网寻找美术/音乐素材，按 [ASSETS.md](../ASSETS.md) 检查后统一处理；本次仅修订文档。

## 风格约束

采用清晰的暖深色轮廓、圆润形状、约 2.5–3 头身人物、轻量笔触和材质纹理。色彩鲜艳而不过度荧光。草地以绿、暖黄、红色蘑菇为主；地下城使用低饱和蓝灰石墙和紫色发光蘑菇，保持人物与攻击的高可读性。

参考《恶果之地》的活泼、夸张形状和细节密度，参考《失落城堡》的手绘场景层次；本游戏始终是严格侧视的横版平台跳跃。不能把这些参考的俯视/斜视镜头或随机地牢玩法移植为本作要求。

两角色共享比例、轮廓厚度和光源。Bill 保留红头巾、突击兵与步枪；洛克人保留蓝头盔、蓝装甲、蓝靴和手炮。人物轮廓约 2–4 个基准视口单位，内部线稍细；不能出现一个写实人、一个像素人和一组平面矢量怪物混搭。

可交互物轮廓比背景更清楚。可站立边缘清晰；背景降低对比和细节密度。子弹、预警与弱点不能被装饰遮挡。怪兽可夸张、可爱并有威胁感，避免压抑血腥气氛。

## 五种怪物与机关的识别要求

| 对象 | 视觉语言 | 必须传达的机制 |
| --- | --- | --- |
| 巡逻蘑菇 | 矮圆红帽、短腿、向前挥帽 | 举帽是预警，挥击范围才危险，普通身体无害 |
| 喷吐蘑菇 | 固定根部、喇叭嘴、鼓胀帽沿 | 吐弹方向与动作明确，危险来自独立孢子弹 |
| 蝙蝠 | 宽翼、悬停和俯冲轨迹 | 只有俯冲亮翼时有攻击区，巡飞/返航身体无害 |
| 荆棘滚兽 | 圆形刺壳、连续滚动、可读尖刺 | 唯一持续触碰伤害普通怪；冰壳盖住刺时暂时安全 |
| 盾壳甲虫 | 低矮宽体、巨大前盾、外露后腹 | 前壳格挡、背部可伤、收招开壳；不靠颜色单独区分 |
| 移动平台 | 清楚水平站立面、轨道/方向标记 | 可搭乘与行程可预判，不伪装成背景 |
| 开关与门 | 同一符号及连接线、亮/灭和开/关形态 | 被攻击激活、对应关系清楚，门打开后路径可见 |

每种敌人使用独立轮廓与动作节奏，不以换色复制同一种怪。怪物受击区、有效攻击范围与视觉形状一致；冻结、解冻宽限、盾壳开合须同步表现。机关资产扩充在草地/地下城两套既有美术内，不引入第三套风格。

## 输出与动画规格

角色单帧/分层基础画布建议 256×256 或更大，透明背景，实际显示高度约 112，脚底锚点固定。Boss 画布建议 512×512，实际显示约 320×300。地形源建议矢量或 128×128 以上 PNG，对应 64×64 逻辑格；背景每层至少 1920×1080，横向无缝可循环。

使用线性过滤和高清绘制。禁止像素块、阶梯轮廓、低分辨率放大、原版 NES/SNES 图块、3D 模型渲染和俯视视角。概念图中的尺寸、文字、箱子外观只作方向参考，实际功能与布局按 PRD 实施。

分层图可通过 Godot `AnimationPlayer` / `Skeleton2D` 做动作，但枪口、手炮、角色脚底和碰撞体应始终稳定。只缩放/旋转一张人物全身图不能替代完整跑步与射击动作。

制作单项资源时，在概念图的方向基础上使用更明确的资源提示词：

> 明亮手绘卡通的 2D 侧视游戏资源，平滑高清轮廓、暖深色粗线、圆润比例、轻量笔触，保持本项目角色设计和光源一致。主体为【角色或物件】，需要【动作或状态】，面向右，脚底与中心锚点固定，透明背景，主体完整、边缘干净。完全非像素，无文字、水印、俯视、透视或 3D。动画各帧保持脸、衣服、装甲、枪与四肢比例一致。

逐项生成或重绘后实际检查，再制作/检查动画。不得仅因为工具返回图片就认定资源符合全部规格。
